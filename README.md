
# API Catalog Practical Assessment

Welcome! This practical assessment evaluates your ability to translate a user story into executable code and unit tests.

## 📖 User Story

> "As an API Consumer, I need to filter APIs by status, so I can quickly find which APIs are Production-Ready."

### Acceptance Criteria:

1. Filter APIs by statuses: **Development**, **Production**, **Deprecated**.
2. Default view shows all APIs without filtering.
3. Display "No APIs found matching the selected criteria." if no APIs match.
4. Bonus: Filters persist across navigation.

## 🛠️ What to Do

- Fork and clone this repository.
- Branch from `main`: `feature/api-filtering`.
- Implement functionality in `ApiList.tsx`.
- Write comprehensive unit tests in `ApiList.test.tsx`.
- Commit clearly and regularly following good SDLC practices.
- Submit a clear and descriptive Pull Request explaining your solution.
